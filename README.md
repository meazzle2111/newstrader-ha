# NewsTrader – Home-Assistant-Add-on

Portfoliomanager mit Nachrichtenanalyse (KI), Trade-Republic-Abgleich, täglichem Hebel-Vorschlag und einem
Zocker-Experiment mit Spielgeld. Läuft als Add-on in Home Assistant (Ingress-Oberfläche, Push über die HA-App).

## Installation

1. Home Assistant → **Einstellungen → Add-ons → Add-on-Store** → ⋮ → **Repositorys**
2. Die Adresse dieses Repositorys hinzufügen
3. **NewsTrader** installieren, unter „Konfiguration“ Schlüssel und Benachrichtigungsdienst eintragen, starten

## Updates

Neue Versionen erscheinen in Home Assistant automatisch als Update beim Add-on.

> Kein Anlagerat. Empfehlungen und Hebel-Vorschläge sind Experimente – Hebelprodukte können wertlos verfallen.
